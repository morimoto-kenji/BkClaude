Becky! Claude Plugin  1.0.0-rc.1
====================================

Becky! Internet Mail のプラグインです。Anthropic の Claude を使って、メールの
要約・翻訳、返信の下書き、本文の校正を行います。

1. 必ずお読みください
----------------------

このプラグインは、処理対象のメール本文を Anthropic の API に送信します。

  - 要約・翻訳(日):   表示中のメールの本文とヘッダ (From/To/Cc/件名/日付)
  - 下書き・校正・翻訳(英): 作成中のメール本文のうち、引用より上の部分
                       (引用部分と署名は送信しません)
  - 送信済みメールの学習: 学習フォルダ内の送信メール本文 (引用除去済み)

送信先は Anthropic のみで、他の第三者には送りません。プラグインの作者も
内容を受け取りません。ただし、社外秘や個人情報を含むメールにこの機能を
使ってよいかは、ご自身の組織の規程に従って判断してください。

利用には Anthropic の API キーが必要です。API の利用料は Anthropic から
ご自身に請求されます。このプラグイン自体は無料ですが、API 利用料は
別途かかります。


2. 動作環境
-----------

  - Becky! Internet Mail ver.2 (32 ビット版)
  - Windows 10 / 11 (64 ビット Windows でも動作します)
  - インターネット接続
  - Anthropic API キー

追加のランタイムは不要です。DLL は Windows 標準のライブラリのみを使用
しています。


3. インストール
---------------

  1. Becky! を終了します。
  2. BkClaude.dll を Becky! の PlugIns フォルダにコピーします。
       例: C:\Program Files (x86)\RimArts\B2\PlugIns\
     (このフォルダへの書き込みには管理者権限が必要な場合があります)
  3. Becky! を起動します。プラグインの読み込みを確認するダイアログが
     表示されたら「はい」を選びます。


4. 初期設定
-----------

  1. Anthropic Console (https://console.anthropic.com/) で API キーを
     取得します。アカウントの作成とクレジットの購入が必要です。
  2. Becky! の「ツール」→「プラグインの設定」→「Becky! Claude Plugin」
     を開きます。
  3. 「Claude 設定」の「APIキー」欄にキーを貼り付けます。
  4. 「接続を確認」を押します。「OK: API キーは有効です。」と表示されれば
     設定完了です。
  5. 「OK」で閉じます。

API キーは Windows の DPAPI で暗号化して保存されます。同じ Windows
ユーザーアカウントでのみ復号できます。

モデルは既定で Claude Haiku 4.5 です。より高品質な結果が必要な場合は
Sonnet 5 または Opus 5 を選べます (利用料も高くなります)。


5. 機能と呼び出し方
-------------------

すべての機能は右クリックメニューと「ツール」メニューの両方から呼び出せ
ます。

■ 受信メールに対して (メール一覧を右クリック / メイン画面の「ツール」)

  Claude でメールを要約
      表示中のメールを 3 つの欄に整理します。
        - メール送受信者:   誰から誰へのメールか
        - メールの要約:     本文の要点。上位の項目だけ読めば全体が分かる
                            ように構成されます
        - メールへの推奨対応: 対応の要否と、必要なら具体的な行動
      結果画面の「返信」「転送」ボタンから、そのまま返信・転送できます。

  Claude でメールを翻訳(日)
      表示中のメールを日本語に翻訳します。日本語のメールはそのまま返り
      ます。

  どちらも結果を一定時間キャッシュします (既定 24 時間)。同じメールで
  もう一度実行しても API は呼ばれません。

■ 作成中のメールに対して (本文を右クリック / 作成画面の「ツール」)

  Claude で本文を下書き
      返信の下書きを作成します。引用より上に書いたメモ (「了解、来週
      で」など) を元に、学習した文体で本文を書きます。何も書いていない
      場合は、元のメールに対する無難な返信を作ります。
      下書きはそのまま本文に入ります。

  Claude で本文を校正
      引用より上の本文を校正します。誤字、変換ミス、敬語の不統一、不自
      然な表現を直します。書き直しではなく修正なので、文体や構成は保た
      れます。
      適用前に確認画面が出ます。赤の取り消し線が削除、青が追加です。
      「修正の理由」欄に、何をなぜ直したかが一覧されます。「適用」を押
      すまで本文は変わりません。

  Claude で本文を翻訳(英)
      引用より上の本文を英語にします。日本語なら英文ビジネスメールとし
      て、英語なら校正して返します。
      適用前に確認画面が出ます。

  作成中メールの機能は、引用と署名を送信も変更もしません。引用より上に
  書いた部分だけが対象です。

■ 送信時 (自動)

  添付ファイルの付け忘れ確認 → 7 章


6. 送信済みメールの学習
-----------------------

下書き機能が「あなたの文体」で書くために、送信済みメールを学習させ
ます。学習しなくても下書きは動きますが、一般的な文体になります。

■ 手順

  1. フォルダツリーで、そのメールボックスの「送信済み」フォルダを右ク
     リックし、「Claude で送信済みメールを学習」を選びます。
  2. 進捗ダイアログが出ます。数分かかります (メール数によります)。
  3. 完了すると、学習した内容の概要が表示されます。

送信済みメールを別のフォルダに振り分けている場合は、そのフォルダを右
クリックして「Claude で学習フォルダとして指定」を選んでから、上の手順
を行います。

■ 何を学習するか

  - 敬語の程度、書き出しと結びの定型、一人称、文の長さ、よく使う言い
    回し、依頼・謝罪・断りの書き方
  - 宛先による書き分け (取引先と身内で変える、など)
  - 新規メールと返信での違い
  - 添付ファイルを知らせるときの言い回し (7 章)

■ 何を送信するか

  学習フォルダの中の新しい順に最大 200 通 (設定で変更可) の本文を、引
  用部分を除いた上で Anthropic に送ります。件名や宛先の表示名は送りま
  せん。宛先のメールアドレスは書き分けの学習のために送ります。

■ 学習はメールボックスごと

  メールボックス (メールアドレス) ごとに別々に学習します。仕事用と私用
  で文体が違っても、それぞれの文体で下書きされます。

■ 学習データの削除

  「プラグインの設定」→「送信済みメール学習設定」の一覧でメールボック
  スを選び、「学習データ削除」を押します。


7. 添付ファイルの付け忘れ確認
-----------------------------

本文に「添付の通り」のような言葉があるのに添付ファイルがない状態で送
信しようとすると、確認ダイアログが出ます。

  ┌────────────────────────────┐
  │ このメールには添付ファイルがありません。            │
  │ 本文に次の表現があります。                         │
  │     「添付の通り」                                │
  │ 添付し忘れていないか確認してください。               │
  │                                                │
  │           [ このまま送信する ] [ 編集へ戻る ]       │
  └────────────────────────────┘

「編集へ戻る」が既定です。Enter、Esc、閉じるボタンはすべて作成画面に戻
ります。送るには「このまま送信する」を明示的に選びます。

■ 判定に使う言葉

  送信済みメールの学習で、あなたが添付を知らせるときに実際に使う言い回
  しを抽出します (添付があるメールにだけ現れる表現)。学習前は
  「添付します」など数語の内蔵リストで動きます。

  学習した言い回しは次のファイルに 1 行 1 件で保存されます。

    (Becky! のデータフォルダ)\BkClaude\attach_<メールボックス>.txt

  このファイルは手で編集できます。

    - 警告が出てほしい表現が拾われていない → 1 行足す
    - 添付がないメールでも警告が出る表現がある → その行を消す
      (行頭に # を付けると無効化できます)

  再学習より確実なので、気になったらまずここを直してください。

■ この機能は API を使いません

  送信時の判定は保存済みの言い回しとの照合だけです。送信が遅くなること
  も、通信が発生することもありません。

■ 無効にする

  「プラグインの設定」→「添付忘れ確認設定」のチェックを外します。学習
  は設定に関係なく行われるので、再度有効にすればすぐ動きます。


8. 設定項目
-----------

「ツール」→「プラグインの設定」→「Becky! Claude Plugin」

■ Claude 設定
  APIキー         Anthropic の API キー
  モデル          Haiku 4.5 (既定) / Sonnet 5 / Opus 5
  接続を確認      キーの有効性と、選択したモデルが使えるかを確認

■ キャッシュ設定
  要約の保持時間  要約結果を保持する分数 (既定 1440 = 24 時間、0 で無効)
  翻訳の保持時間  同上
  ○○キャッシュを削除  保持している結果をすべて消す

■ 送信済みメール学習設定
  過去 N ヶ月     この期間より古いメールは学習しない (既定 0 = 制限なし)
  最大 N 通       学習するメール数の上限 (既定 200)
  学習フォルダ解除  選択したメールボックスの学習フォルダ指定を解除し、
                  学習データも削除
  学習データ削除  選択したメールボックスの学習データを削除 (指定は残る)

■ 添付忘れ確認設定
  添付ファイルの付け忘れを確認する  送信時の確認の有効/無効 (既定: 有効)

■ ライセンス設定
  ライセンスキー  13 章をご覧ください


9. 保存されるデータ
-------------------

Becky! のデータフォルダの BkClaude フォルダに保存されます。通常は次の
場所です。

  C:\Users\<ユーザー名>\AppData\Roaming\RimArts\Becky\BkClaude\

  config.ini            設定、学習フォルダの指定
  apikey.bin            API キー (DPAPI で暗号化)
  style_<箱>.txt        学習した文体 (日本語の説明文)
  attach_<箱>.txt       添付を知らせる言い回し (1 行 1 件)
  result_cache.json     要約・翻訳の結果キャッシュ
  learn.log             学習の実行記録

学習した文体 (style_*.txt) は普通のテキストなので、読めば何を学習した
かが分かります。下書きの文体が意図と違うときは、まずこのファイルを読ん
でください。原因が書いてあることが多いです。


10. エラーが出たとき
--------------------

エラーは「何をすればよいか」と「何が起きたか」の 2 段で表示されます。
上の段に従ってください。下の段は問い合わせや調査のための生の情報です。

  API キーが無効です            設定画面でキーを確認
  クレジット残高が不足          Anthropic Console で請求設定を確認
  利用制限に達しました          しばらく待って再試行
  Anthropic 側で一時的な障害    しばらく待って再試行
  応答がありませんでした        ネットワークが遅いか混雑。再試行
  api.anthropic.com に接続できません
                                インターネット接続、ファイアウォール、
                                プロキシの設定を確認
  応答が出力上限に達し、途中で切れました
                                メールが非常に長い場合に起こります。
                                下の段のトークン数を添えて報告してく
                                ださい


11. 制限事項
------------

  - HTML 形式のメールの作成には対応していません。テキスト形式で作成
    してください。HTML メールの要約・翻訳(日) は可能です (タグを除去
    して処理します)。
  - Claude 専用です。他の AI サービスには対応しません。
  - 本文の一部を選択して処理することはできません。作成中メールの機能
    は常に「引用より上の全体」が対象です。
  - 生成された文章は必ず内容を確認してから送信してください。AI は事
    実と異なる内容を書くことがあります。


12. アンインストール
--------------------

  1. Becky! を終了します。
  2. PlugIns フォルダから BkClaude.dll と BkClaude.txt を削除します。
  3. 保存データも消す場合は、9 章の BkClaude フォルダを削除します。
     API キーもここに含まれます。
